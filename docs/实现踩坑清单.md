# 实现踩坑清单（全量 19 条）

> 从 WorkBuddy 工作区记忆迁出（2026-11-08 清理）。HANDOVER §7 只保留最贵的 10 条，全量清单以本文件为准。
> 每条都是写代码时才暴露、文档未覆盖的教训，勿重蹈。

1. **SQLite 上 `BigInteger` 主键不自增** → 必须 `BigInteger().with_variant(Integer, "sqlite")`，否则建记录报 `NOT NULL constraint failed`。
2. **`ActionContext.variables` 必须按"每个用例一份"复用**，不能每步新建 —— 否则 `get_text` 存的 `${var}` 到下一步变字面量，断言静默失败。
3. **回退链每条候选只等 `min(总超时, 2.5s)`，最后一条才用满**。否则"首选写错"要白等 15s，用户以为卡死（实测 18s → 5.7s）。
4. **不要 `session.expire_all()`**：会把调用方持有的对象一并置过期，之后任何属性访问都在 greenlet 外触发懒加载 → MissingGreenlet。改法：就地同步被批量 UPDATE 影响的 ORM 对象。
5. **纯字符串判断的函数不要写成 `async`**（如 `move_guard`），否则忘记 await 时循环检测**静默失效**，测试才会发现。
6. 前端构建需要 `@types/node`（vite.config 用了 `node:url`），否则 `vue-tsc --noEmit` 直接失败。
7. **FastAPI 0.146 起 `include_router` 不再摊平到 `app.routes`**，统计路由必须读 `app.openapi()["paths"]`。
8. **扩展一个引擎的真实成本 = 1 个适配器文件 + 3 处声明**（`ENGINES` / `PLATFORM_ENGINES` / `CAPABILITY_MATRIX`），不是文档说的"注册一行"；三处由启动校验强制一致。加动作同理（`ACTION_CATALOG` + 矩阵）。
9. **Pydantic 的 422 必须自己接管**，否则返回 `{"detail":...}` 破坏统一错误信封（已加 `validation_error_handler`）。
10. **`create_all` 不会给已有表加列** → 加列后旧开发库必须重建（无 Alembic 期间）。正式解：GAP-33 引入 Alembic。
11. **M3.1 执行语义（已冻结 FR28–FR40）**：`POST /executions` 202；进程内 FIFO 队列 + `Semaphore(max_concurrent_executions=2)`；`RETRY` 逐次落 `attempt`；取消只在步骤间；`artifact` 由执行器落库（适配器只给路径）；报告 HTML+JSON 先删后插；WS 事件名沿用 M1 + `step.retried`；启动把残留 RUNNING/PENDING 置 ERROR；**单进程语义**（多 worker 需 Redis）。
12. **M3.3 四层模型（D27/FR43–45）**：`项目 → 用例集(test_suite) → 用例 → 元素+动作`；用例集是执行单元（单次/定时）。**只存 case_id、不复制步骤**；执行时把 `enabled=1` 成员展开为 `case_ids` 快照；`execution` 存 `suite_id` + `suite_name` 快照。定时用 **APScheduler 内存 job store**（5 段 cron / misfire 60s / 重启从 DB 重建），与队列同为单进程语义。
13. **M3.2 语义（FR46–FR53，已冻结）**：
    - `check_exists` **必须沿回退链逐条判断** —— 只查首条会让"首选写错、回退可用"的元素被断言误判（实测 3 个 smoke 项失败）。
    - 断言在 `timeout_ms` 窗口内轮询，间隔 `UIP_ASSERT_POLL_INTERVAL_MS=200`，**不设固定次数**。
    - 产物下载双重校验：归属 + `realpath` 必须在 `artifacts_dir`；API **不返回服务器路径**。
    - 报告链接用 `/api/v1/executions/{id}/artifacts/{aid}`；报告默认 `Content-Disposition: inline`（否则 iframe 会触发下载）。
    - `report` 唯一键 `uk_report_execution_format` + `begin_nested()` savepoint 兜并发 upsert。
    - 步骤写入口统一校验（动作/params/元素归属同项目/seq），**新增与修改共用一份规则**。
    - `screenshot.target ∈ {page, element}`；`element` 需绑定元素，`page` 不允许绑定 —— 执行器按 `params.target` 解析 chain，不能只看 `requires_element`。
14. **Alembic 用法**：`backend/alembic.ini` 保持 **ASCII only**（configparser 用系统 locale 读，中文注释在 Windows 会 UnicodeDecodeError）；URL 由 `env.py` 从 `settings.database_url` 读取；开发库由 `create_all` 建出后需 `alembic stamp head` 一次，之后改表走 `revision --autogenerate` + `upgrade head`。
15. **前端字段名必须核对后端响应**：`/actions` 返回 `action_key` 而非 `key`，写错不会报错，只是所有中文名静默变英文。
16. **桩适配器签名必须与 `params_schema` 完全一致**：少一个参数时 TypeError 发生在函数体之前，`_todo()` 的 NotImplementedError 根本抛不出来 —— "待实现"与"签名不匹配"会混在一起。
17. **M3.4 一键接入（`POST /scaffold`，FR54–FR59）**：
    - 七步严格串行 S1→S7：项目 → 执行目标 → 元素 → 定位符 → 用例+步骤 → 用例集 → 执行；后一步的输入是前一步的 id（外键语义，不可并行）。
    - **静态校验必须在写库前**（URL / 动作 / params / element_key / 定位类型）；失败时零写入。
    - **补偿而非单事务**：底层服务各自 commit 且签名已冻结；补偿按 suite→case→locator→element→target→project 逆序软删，只保证 API 视角无残留。
    - 幂等键：`project.code` / `(project_id, base_url)` / `(project_id, name)` / `(project_id, title)` / `(suite_id, case_id)`；**执行不幂等**。
    - **复用 case 时绝不重复加步骤**；但复用的 case 若 0 步骤必须补步骤（否则"0 步通过"骗人）。
    - Scaffold 生成的 `navigate` 默认 `wait_until=load`（手写用例默认仍是 `domcontentloaded`）。
    - 校验顺序有讲究：先判"项目 code 冲突"再判"只支持 WEB"，否则已存在的 Android 项目会报错码不准。
18. **M3.5 元素扫描（D28，FR60–FR64）**：
    - **D28 放开 D14 边界**：不做交互式点选，但允许按 URL 批量扫描；定位符自动生成、**人工确认才落库**。
    - `scan_dom()` 是**诊断方法不进 action_catalog**（字典仍 51 条）；基类默认 NotImplementedError，playwright 覆写。
    - 扫描（`POST /element-scan`）**不落库**；导入（`/element-scan/import`）才写。两者必须分开（人工确认前提）。
    - 定位符优先级：testid > id > name > role+aria > aria-label > placeholder > alt > title > href > src > text(2~30字) > css。
    - 分级：strong(testid/id/name) / medium / weak(class/text)。前端**默认只勾强/中**。
    - 容器（div/span/**form**/table…）默认跳过，带 testid/id/role 保留；`form` 是容器不是交互元素（F-M3.5-1）。
    - 同项目扫描用进程内锁串行（避免并发开浏览器）；等待固定 `networkidle`。
19. **`execution_target` 至今没有创建/编辑端点**（只有 GET 列表），只能通过 scaffold/seed 建 —— 登记为 GAP-42；写 smoke 时想用 API 建 target 会踩空。

## M4 追加（真机侧，详见 M4 详细设计 §7）

20. **环境里的 `HTTP_PROXY` 会代理 `127.0.0.1:4723`** → Appium 客户端必须 `NO_PROXY=127.0.0.1,localhost`，否则元素查找报 selector not present。
21. **整屏手势必须内缩**：从屏顶下滑会拉下通知栏，之后所有定位落空；旋转锁定要翻译成「开自动旋转/App 锁方向」。
22. **执行必须有限时间结束**（D43）：驱动瞬时 500 限次 3 次 + 命令硬上限；执行器单步硬上限 `max(30s, timeout×2+30s)`，否则「执行永远 RUNNING」。

## M3.8 追加（2026-11-08，specs/001 实现期）

23. **iframe 栈跨用例泄漏（既有隐患，M3.8 修复）**：`_frame_stack` 原先跨用例不清理——用例 A 进 iframe 未退出，用例 B 的所有定位全落在 iframe 里。修复：`EngineAdapter.reset_case_scope()` 生命周期钩子（基类 no-op，Playwright 覆写清 route+frame 栈），执行器在**每个用例开始**时调用（前用例异常中断也能兜住）。
24. **`select(实体)` 返回 Row 不是实体**：`session.execute(select(ActionCatalog)).all()` 拿到的是 Row 包装，`row.action_key` 直接 AttributeError——必须 `.scalars().all()` 解包。单列 `select(实体.列)` 则无此问题。
25. **`render` 只认 `dict` 不认 Mapping**：变量渲染用 `ChainMap` 做双层视图时，`isinstance(cur, dict)` 为 False 导致变量静默保留原样——改为 `isinstance(cur, Mapping)`（collections.abc）。教训：凡是"查一层 dict"的工具函数，收窄类型会杀掉协议传参。
26. **`--app-dir` 不改 cwd**：`uvicorn --app-dir` 只解决模块导入，**相对路径（SQLite `./data/uitest.db`、artifacts_dir）仍按进程 cwd 解析**——起服务必须 `cd backend && uvicorn ...`，否则静默新建空库（症状：seed 数据"消失"、target 解析不到、navigate 相对路径炸 invalid URL）。
27. **动作参数名与 Python 内置冲突**：`mock_route` 的 schema 属性叫 `json`，FR4 冻结约定（kwargs 名 == schema 属性名）迫使适配器签名必须叫 `json`——模块 import 改别名 `import json as _jsonlib`，代价写进 docstring。
28. **门禁工具必须 cd 到 backend 跑，否则"本地绿"是假象（CI 红过一次）**：`ruff check app tests` 在错误 cwd 下执行时 ruff 找不到 `backend/pyproject.toml` 的规则集（select=E/F/I/UP/B/ASYNC + line-length=100），退化到默认规则集（只有 E4/E7/E9/F），E501/ASYNC109/B017 全部漏检——M3.8 批次 4 处违规就这么溜进 CI 的。**任何 lint/测试命令都从 backend 目录发起**（或直接用 `scripts/ci_local.sh`）。另：`# noqa: XXXX` 注释后不能跟中文（ruff 解析 noqa 码要求纯 ASCII，否则报 Invalid noqa 且不生效）。
