## 文档维护规则

1. **一处事实，一处定义**：DDL 的最终事实源是 `backend/sql/schema.sql`；文档附录只是快照。
2. **改冻结项必须留痕**：每份 D2-Mx 文末有「变更记录」表，改 §6.1 冻结项必须追加条目并回写上游。
3. **文档与代码不一致时，先修文档再修代码**（或同时），不允许"代码是对的、文档先放着"。
